## Contribuições nos SDKs

Os SDKs do Clowk aceitam contribuições. Se você encontrar um bug ou quiser adicionar um recurso:

1. Faça um fork do repositório
2. Crie uma branch para o recurso
3. Faça suas alterações
4. Envie um pull request

## SDKs da comunidade

Quer criar um SDK do Clowk para um framework que ainda não suportamos? Queremos ajudar. Fale com a gente em [support@clowk.in](mailto:support@clowk.in) e daremos orientações sobre o contrato da API e os testes.

## Documentação

Achou um erro de digitação ou quer melhorar a documentação? O código-fonte da documentação fica junto com a landing page. Pull requests são bem-vindos.

## Relatos de bug

Relate bugs em [support@clowk.in](mailto:support@clowk.in) com:

- Passos para reproduzir
- Comportamento esperado
- Comportamento real
- Versão do SDK e runtime

## Pedidos de recurso

Envie um email para [support@clowk.in](mailto:support@clowk.in) com o seu caso de uso. Priorizamos recursos pela demanda e pelo alinhamento com o modelo de broker do Clowk.
