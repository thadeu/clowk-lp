## GET /api/v1/sessions/:id

Busca uma sessão pelo `session_id` (`clk_session_UUID`). Retorna só sessões da instância ligada à sua secret key.

## Requisição

```bash
curl https://myapp.clowk.dev/api/v1/sessions/clk_session_a1b2c3d4-e5f6-7890-abcd-ef1234567890 \
  -H "X-Clowk-Secret-Key: sk_live_..."
```

### Headers

| Header | Obrigatório | Descrição |
|--------|----------|-------------|
| `X-Clowk-Secret-Key` | Sim | A secret key da sua instância |

### Parâmetros de caminho

| Parâmetro | Tipo | Descrição |
|-----------|------|-------------|
| `id` | `string` | O valor de `session_id` (formato: `clk_session_UUID`) |

## Resposta

### 200 — Sessão encontrada

```json
{
  "id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "resource": "session",
  "data": {
    "session_id": "clk_session_a1b2c3d4-e5f6-7890-abcd-ef1234567890",
    "user_id": "b2c3d4e5-f6a7-8901-bcde-f12345678901",
    "provider": "google",
    "name": "Jane Doe",
    "email": "jane@example.com",
    "ip_address": "203.0.113.42",
    "geo_data": {},
    "logged_in_at": "2026-03-20T10:30:00Z",
    "last_signin_at": "2026-03-20T10:30:00Z",
    "revoked_at": null,
    "active": true
  }
}
```

### 401 — Não autorizado

```json
{ "error": "Unauthorized" }
```

### 404 — Não encontrada

```json
{ "error": "Session not found" }
```
