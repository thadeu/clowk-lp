## GET /.well-known/openid-configuration

O Clowk expõe um endpoint básico de descoberta OpenID Connect. Assim, ferramentas compatíveis com OIDC descobrem os endpoints de autenticação do Clowk automaticamente.

## Requisição

```bash
curl https://myapp.clowk.dev/.well-known/openid-configuration
```

Não é preciso autenticação.

## Resposta

```json
{
  "issuer": "https://myapp.clowk.dev",
  "authorization_endpoint": "https://myapp.clowk.dev/oauth/authorize",
  "token_endpoint": "https://myapp.clowk.dev/api/v1/tokens/verify",
  "userinfo_endpoint": "https://myapp.clowk.dev/api/v1/users",
  "response_types_supported": ["code"],
  "subject_types_supported": ["public"],
  "id_token_signing_alg_values_supported": ["HS256"]
}
```

| Campo | Descrição |
|-------|-------------|
| `issuer` | A URL base do Clowk |
| `authorization_endpoint` | Onde o fluxo OAuth começa |
| `token_endpoint` | Onde verificar tokens |
| `userinfo_endpoint` | Onde buscar dados do usuário |
| `response_types_supported` | Só o fluxo authorization code é suportado |
| `id_token_signing_alg_values_supported` | Os tokens são assinados com HS256 |

## Fluxo OAuth

O Clowk usa o fluxo authorization code:

1. Redirecione o usuário para `/oauth/authorize` com um `provider` e um `redirect_uri`
2. O Clowk cuida da troca OAuth com o provedor (Google, GitHub, Twitter)
3. Em caso de sucesso, o Clowk redireciona de volta para o seu `redirect_uri` com o parâmetro de query `token`
4. Verifique o token com `POST /api/v1/tokens/verify` ou decodifique-o localmente com a sua secret key

```http
GET /oauth/authorize?provider=google&redirect_uri=https://app.example.com/auth/callback
```

### Provedores suportados

| Provedor | Scopes |
|----------|--------|
| Google | `openid`, `email`, `profile` |
| GitHub | `user:email`, `read:user` |
| Twitter | `tweet.read`, `users.read`, `offline.access` |

### Parâmetro state

Cada requisição OAuth gera um valor `state` único para evitar ataques CSRF. O state expira em 10 minutos. Os fluxos do Twitter também usam PKCE (code challenge e verifier).
