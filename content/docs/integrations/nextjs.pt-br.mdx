## Instalação

```bash
pnpm add @clowk/nextjs
```

`@clowk/nextjs` já traz `@clowk/react` e `@clowk/core` como dependências.

## Variáveis de ambiente

```bash title=".env.local"
NEXT_PUBLIC_CLOWK_PUBLISHABLE_KEY=pk_live_...
CLOWK_SECRET_KEY=sk_live_...
```

## Middleware

Proteja rotas com o middleware do Next.js:

```typescript title="middleware.ts"
import { clowkMiddleware } from '@clowk/nextjs'

export default clowkMiddleware({
  secretKey: process.env.CLOWK_SECRET_KEY,
  publicRoutes: ['/', '/sign-in', '/sign-up'],
  signInUrl: '/sign-in',
})

export const config = {
  matcher: ['/((?!_next/static|_next/image|favicon.ico).*)'],
}
```

### Opções do middleware

| Opção | Tipo | Descrição |
|--------|------|-------------|
| `secretKey` | `string` | Secret key para verificar o JWT |
| `publicRoutes` | `string[]` | Rotas que não exigem autenticação |
| `signInUrl` | `string` | URL de redirect para usuários não autenticados |

## Server Components

Acesse o usuário autenticado em Server Components com a função `auth()`:

```tsx title="app/dashboard/page.tsx"
import { auth } from '@clowk/nextjs'
import { redirect } from 'next/navigation'

export default async function Dashboard() {
  const { user, signedIn } = await auth({
    secretKey: process.env.CLOWK_SECRET_KEY,
  })

  if (!signedIn) redirect('/sign-in')

  return (
    <div>
      <h1>Hello, {user?.name}</h1>
      <p>{user?.email}</p>
    </div>
  )
}
```

### Tipo de retorno de `auth()`

```typescript
interface AuthResult {
  user: JwtPayload | null
  token: string | null
  signedIn: boolean
}
```

## Route Handlers

```typescript title="app/api/profile/route.ts"
import { auth } from '@clowk/nextjs'
import { NextResponse } from 'next/server'

export async function GET() {
  const { user, signedIn } = await auth({
    secretKey: process.env.CLOWK_SECRET_KEY,
  })

  if (!signedIn) {
    return NextResponse.json({ error: 'Unauthorized' }, { status: 401 })
  }

  return NextResponse.json({ user })
}
```

## Client Components

`@clowk/nextjs` reexporta todos os componentes e hooks de `@clowk/react`:

```tsx title="components/header.tsx"
'use client'

import { SignInButton, SignOutButton, useAuth } from '@clowk/nextjs'

export function Header() {
  const { signedIn, user } = useAuth()

  if (!signedIn) return <SignInButton />

  return (
    <div>
      <span>{user?.name}</span>
      <SignOutButton />
    </div>
  )
}
```

Exports de cliente disponíveis: `ClowkProvider`, `useAuth`, `useToken`, `useClowk`, `SignInButton`, `SignUpButton`, `SignOutButton`.
